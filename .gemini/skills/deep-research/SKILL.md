# Deep Research & Literature Synthesis

Automate structured analysis of prior art, competitive solutions, and architectural tradeoffs.

## Analysis Structure

1. **Prior Art & Ecosystem Mapping:** Identify existing open-source and commercial implementations solving similar problems.
2. **Constraint Extraction:** Map hard technical limitations (compute costs, bandwidth, latency SLAs, API rate limits).
3. **Tradeoff Matrix:** Generate a structured comparison evaluating candidate solutions against critical criteria.

## Tradeoff Matrix Format

| Solution / Approach | Advantages | Disadvantages | Latency / Cost | Operational Burden |
| :--- | :--- | :--- | :--- | :--- |
| **Approach A** | High throughput, zero deps | High memory footprint | Low / `$0.00` | Minimal |
| **Approach B** | Highly extensible, managed | Vendor lock-in risk | Med / `$0.05`/k req | High |

## Output Deliverables
- Executive technical synthesis (max 300 words).
- Structured Tradeoff Matrix.
- Clear, evidence-grounded recommendation on the optimal path forward.
